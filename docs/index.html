Memory MCP Server

A locally running memory management server for Claude Desktop. Remember preferences, interests, and personal context — entirely on your own machine.

Download latest release View on GitHub

Features

🗂️ Full CRUD

Create, read, update, and delete user memory entries through simple MCP tools.

💾 Local JSON storage

Memory is saved automatically to a JSON file you control — no cloud, no external database.

📜 Operation logging

Every memory operation is logged to a JSONL audit trail for transparency.

🖥️ Desktop extension

Packaged as a .dxt file — drag, drop, and enable inside Claude Desktop.

🌐 Multi-platform

Runs on Windows, macOS, and Linux, locally or via Docker.

🔗 Knowledge-graph ready

Entities saved with [[wiki-links]] for Obsidian-style graph visualization.

Quick start

Install as a Claude Desktop extension

  1. Download the latest .dxt from the GitHub releases page.
  2. Extract the downloaded file.
  3. In Claude Desktop's settings, open the Extensions page and drag and drop the extracted .dxt file.
  4. When enabling it, set the location for your save file (required).

Run with Docker

# Development
docker compose up

# Production build
docker build -t memory-mcp .
docker run -p 58902:58902 -v ./memory_data.json:/app/memory_data.json memory-mcp

Run locally

pip install -r requirements.txt
python main.py

Memory format

Every memory entry is stored as a simple, portable JSON object:

{
  "key": "memory_YYYYMMDDHHMMSS",
  "content": "User is [specific info]",
  "timestamp": "YYYY-MM-DDTHH:MM:SS.ssssss"
}
